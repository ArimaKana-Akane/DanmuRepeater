# 🤖 烂梗机 

> 多平台直播弹幕自动复读助手 · Tampermonkey 用户脚本

[![Tampermonkey](https://img.shields.io/badge/Tampermonkey-✓-green.svg)](https://www.tampermonkey.net/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
![Version](https://img.shields.io/badge/version-1.1.20-orange.svg)

「烂梗机」是一个运行在浏览器中的油猴脚本，监听直播间弹幕流，识别高频 / 热门弹幕，并自动在聊天框复读。支持 **斗鱼 / 虎牙 / Bilibili / 抖音** 四大直播平台。

> ⚠️ **免责声明**：本项目仅用于学习与个人娱乐。请遵守各直播平台的服务条款与社区规范，合理控制使用频率，勿用于刷屏、引流、广告等违规行为。使用者自行承担一切后果。

## ✨ 功能特性

- 🌐 **多平台支持**：斗鱼、虎牙、B站、抖音自动识别，无需配置
- 🧠 **智能候选**：基于弹幕频次 + 长度 + 优先词加权评分，候选词实时刷新（1 秒）
- 🔢 **候选上限**：候选词池限制最高 50 条，避免池子过大、输出陈旧
- 📊 **DPM 精准统计**：精确识别弹幕节点（含批量渲染容器），每分钟弹幕数（DPM）计算准确
- 🎯 **趋势置顶**：频次达到阈值的热门弹幕自动置顶优先发送
- 🚫 **智能去重**：发送过的弹幕及其近似变体（如 `66666` vs `666666`）自动排除，避免重复刷屏
- 🧪 **灵活过滤**：屏蔽词（支持正则）、长度 / 包含 / 正则筛选规则
- ⭐ **优先词**：指定词汇获得权重加成，优先被选中
- 🎭 **多模式**：根据 DPM 自动切换 佛系 / 正常 / 疯狂 三档发送频率
- 🎨 **主题定制**：背景、文字、强调色、透明度、字号、圆角全可调
- 🐛 **全链路日志**：错误日志可视化 + 一键导出，便于排查
- 🖱️ **可拖拽面板**：悬浮面板位置可记忆，全屏时自动隐藏
- 🔧 **模块化架构**：27 个清晰分区，正则缓存、单例调度链，易于维护

## 📦 安装

### 环境要求

- Chrome / Edge / Firefox / Safari 等支持 Tampermonkey 的浏览器
- [Tampermonkey](https://www.tampermonkey.net/) 扩展（或同等用户脚本管理器）

### 安装步骤

1. 安装 Tampermonkey 浏览器扩展
2. 打开 [烂梗机-1.1.20.user.js](./烂梗机-1.1.20.user.js) 原始文件页（Raw 模式）
3. Tampermonkey 自动弹出安装确认，点击 **安装**
4. 打开任意支持平台的直播间，右下角出现 🤖 悬浮面板即安装成功

### 手动安装

1. 复制脚本内容
2. Tampermonkey 图标 → **管理面板** → **+** 新建脚本
3. 粘贴内容并保存（`Ctrl+S`）

## 🎮 使用方法

### 快速上手

1. 打开目标直播间（如斗鱼某房间）
2. 点击悬浮面板标题栏可折叠 / 展开
3. 拨动面板中的 **开关**，机器人开始工作

### 工作流程

```
直播间弹幕流入
      │
      ▼
MutationObserver 采集（精准节点识别）
      │
      ▼
频次统计 freqMap（上限 500 条）
      │
      ▼
权重评分：频次² × 长度加成 × 优先词加成
      │
      ▼
智能去重 + 候选池（上限 50 条，1 秒实时刷新）
      │
      ▼
加权随机选择（含趋势置顶）
      │
      ▼
平台发送器（填充输入框 → 触发发送）
      │
      ▼
发送历史记录（短时窗口 + 历史队列双去重）
```

### 面板状态说明

| 状态项 | 含义 |
|---|---|
| 模式 | 当前运行模式（关闭 / 佛系 / 正常 / 疯狂 / 错误） |
| DPM | 最近 60 秒捕获的弹幕数（每分钟弹幕量） |
| 候选 | 当前候选词池数量（≤50） |
| 倒计时 | 距下次自动发送的秒数 |
| 上次 / 下次 | 最近发送与即将发送的弹幕预览 |

## ⚙️ 配置详解

点击面板右上角 ⚙️ 打开设置页。

### 📝 弹幕设置

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 最短长度 | 4 | 短于该长度的弹幕不参与候选（如 `666` 会被忽略） |
| 长弹幕阈值 | 15 | 超过该长度的弹幕视为"长弹幕" |
| 长度加成 | 2.5 | 长弹幕的权重倍率 |
| 趋势置顶 | 5 | 频次达到该值的弹幕强制置顶发送 |
| 去重窗口(秒) | 120 | 发送后多少秒内不再重复该弹幕 |
| 历史去重(条) | 25 | 记住最近多少条已发送弹幕用于去重 |

### ⚡ 模式设置

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 疯狂阈值 DPM | 180 | DPM 超过该值进入疯狂模式 |
| 疯狂间隔(秒) | 4 | 疯狂模式发送间隔 |
| 正常阈值 DPM | 80 | DPM 超过该值进入正常模式 |
| 佛系间隔(秒) | 10 | 佛系（默认）模式发送间隔 |

> 正常模式间隔在 6~8 秒之间随机浮动，所有模式发送间隔下限 2 秒。

### 🚫 屏蔽词 & 高级筛选

- **屏蔽词**：`/` 或 `,` 分隔，支持 `/正则/` 形式（如 `/广告.*/`）
- **筛选规则**：每行一条，支持：
  - `length>10` / `length<5` / `length>=10` / `length<=5` / `length==7`
  - `contains:关键词` / `not_contains:关键词`
  - `regex:正则表达式`

### ⭐ 优先词

- 开关启用后，命中的弹幕权重 × 权重加成（默认 3.0）
- 支持 `/正则/` 形式

### 🎨 外观设置

背景色 / 文字色 / 强调色 / 边框色 / 透明度 / 字号 / 圆角，均可自定义，实时预览。

### 🐛 错误日志

- 仅展示 error 级别日志，可一键**清空**或**导出**完整日志（.log 文件）

## ❓ 常见问题

**Q1：候选词一直是旧数据，不更新？**
> 检查机器人开关是否处于打开状态。关闭状态会断开弹幕监听，重新打开即恢复（v1.1.10 起自动处理）。若长时间无弹幕，属正常现象。

**Q2：为什么 `666` 这种短弹幕不会被复读？**
> 默认"最短长度"为 4。弹幕文化中的纯数字短梗（666/2333）如需复读，请在设置中把最短长度调低（如 1）。

**Q3：机器人发消息失败 / 不发送？**
> 请先确认已登录直播平台账号（未登录无法发送）。打开设置页查看"错误日志"，导出日志排查。

**Q4：更换直播间后候选不更新？**
> 直播站为 SPA 应用，切换房间时弹幕容器可能被替换。当前设计为不自动重连（有意为之），刷新页面即可恢复。

**Q5：F12 看不到脚本日志？**
> 斗鱼等平台会劫持 `console.log` 为空函数（页面自身行为）。脚本日志仍可通过设置页"错误日志"查看或导出。
