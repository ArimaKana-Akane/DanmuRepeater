# 🤖 烂梗机

> 多平台直播弹幕自动复读助手 · Tampermonkey 用户脚本

[![Tampermonkey](https://img.shields.io/badge/Tampermonkey-✓-green.svg)](https://www.tampermonkey.net/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

监听 **斗鱼 / 虎牙 / Bilibili / 抖音** 直播间的弹幕流，识别高频 / 热门弹幕并自动复读。
内置「DOM + 协议」双引擎与分层安全护栏，行为可观测、可配置。

> ⚠️ **免责声明**：本项目仅用于学习与个人娱乐。请遵守各平台服务条款与社区规范，
> 合理控制使用频率，勿用于刷屏 / 引流 / 广告。使用者自行承担一切后果。

## 功能特性

- **四大平台全覆盖**：斗鱼、虎牙、Bilibili、抖音，同一套采集 / 决策 / 发送管线；
- **双引擎数据源**：兼容性最好的 DOM 引擎 + 四平台协议引擎（B 站 wss 直连；斗鱼自连 / Hook 双路线；虎牙、抖音被动 Hook 页面连接），支持自动智能选择；
- **智能去重**：规范化文本合并近似弹幕、保护纯数字弹幕（`66666` 可正常复读）、过滤系统弹幕；
- **实时候选池**：2 分钟滑动窗口统计频次，候选词随直播间话题实时刷新，杜绝发送过期弹幕；
- **证据驱动发送**：发送后根据「输入框是否清空」的实测证据决定是否补 Enter——根治各平台「一次发两条」；
- **分层安全阀**：分钟 / 小时 / 日硬上限、最小间隔、同句冷却、平台风控熔断，计数持久化、刷新不丢；
- **多标签页协作**：leader 选举，同一弹幕只由一个标签页发送；
- **完整的可观测性**：面板、设置页、环形事件日志、60s 采集摘要、导入 / 导出 / 诊断快照；
- **零依赖单文件**：一个 `.user.js`，无构建步骤，安装即用。

## 技术路线

烂梗机不是一堆平台 if-else 的堆叠，而是一条贯穿的弹幕处理管线，
每个环节有明确的职责与护栏。整体链路如下：

```
直播间弹幕流
   │
   ▼
┌─ ① 采集层（双引擎互斥）────────────────────────────┐
│  DOM 引擎    MutationObserver 监听弹幕容器，平台选择器   │
│              + 结构判定（系统节点排除）                  │
│  协议引擎    B 站 wss 直连；斗鱼自连 / Hook；虎牙 / 抖音 │
│  （四平台）  被动 Hook 页面连接——认证成功才接管          │
└──────────────┬────────────────────────────────────┘
               ▼
┌─ ② 预处理层 ────────────────────────────────────────┐
│  文本规范化（近似弹幕合并 / 纯数字保护）                 │
│  系统弹幕过滤（欢迎 / 礼物 / 公告 / 进场，结构 + 关键词）  │
│  去重窗口                                               │
└──────────────┬────────────────────────────────────┘
               ▼
┌─ ③ 统计与加权层 ───────────────────────────────────┐
│  2 分钟滑动窗口频次 / DPM 统计                        │
│  元数据加权：独立发言人数 + 频次 + 新鲜度（上限 1.8）    │
└──────────────┬────────────────────────────────────┘
               ▼
┌─ ④ 决策层 ────────────────────────────────────────┐
│  候选池实时刷新（上限 50）                            │
│  阈值 / 间隔策略 / 同句冷却 / 随机跳过                 │
└──────────────┬────────────────────────────────────┘
               ▼
┌─ ⑤ 发送层 ────────────────────────────────────────┐
│  DOM 模拟发送（全平台）：证据驱动 Enter 兜底           │
│  B 站原生发送（可选）：GM_xmlhttpRequest 直发          │
└──────────────────────────────────────────────────┘
        ▲              ▲
        └── ⑥ 安全护栏 ──┘（贯穿全链路，fail-closed）
```

### 各环节的设计取舍

**① 采集：DOM 与协议互斥，而不是叠加**
两个数据源可能同时把同一条弹幕写进统计表，导致频次翻倍。因此协议引擎只有
在 wss 认证成功后才「接管」（暂停 DOM、清空旧统计），掉线立即交还 DOM——
握手期间由 DOM 继续采集，全程没有探测空窗。

- DOM 引擎是**行为基线**：所有平台均可用的保底方案，行为长期冻结，升级只叠加能力不改变既有语义；
- 协议引擎读取的是平台自己的弹幕推送流，不依赖页面 DOM 结构，更稳、更全。B 站为
  wss 直连（也是「协议直发」的地基）；斗鱼支持「自连 + Hook」双路线；虎牙 / 抖音
  被动 Hook 页面已有连接（只读不发，签名 / ack 由页面 SDK 自理）；
- 任一路线认证成功才接管；失败自动换下一路线或回落 DOM（见「平台数据源现状」）。

**⑤ 发送：证据驱动，宁可不发也不双发**
平台清空输入框是异步的——「点完立即补 Enter」在按钮已生效时会再发一次（双发）。
烂梗机统一改为：发送动作后轮询宽限确认，**只有实测输入框仍未清空才补一次 Enter**：

- 按钮有效 → 输入框已清空 → 不补 → 单发；
- 按钮灰态无效（斗鱼登录态实测）→ 输入框未清空 → 补 Enter → 依然发得出去；
- 抖音绝不允许双发，是该模型的最高优先级约束。

**⑥ 安全护栏：默认拒绝，而不是默认放行**
- 首次启用需在面板点一次红色「已知晓」风险确认，未确认不运行（fail-closed）；
- 安全配置只能合并、只能更严：任何残缺配置都无法绕过硬上限；
- 触发风控熔断 / 随机跳过后的发送**不重试**，网络歧义一律按「未发出」以外的错误处理，
  宁可偶发漏发，绝不重复发送。

### 平台数据源现状

| 平台 | 数据源引擎 | 发送通道 | 说明 |
|---|---|---|---|
| 斗鱼 | DOM **或** 协议（智能选择，路线可配） | DOM 模拟（保留 Enter 兜底） | 协议 = 自连 `danmuproxy:8501~8506`（匿名、端口 failover、坏房间 25s 静默看门狗）+ Hook，双路线 |
| 虎牙 | DOM **或** 协议 Hook（智能选择） | DOM 模拟 | 被动监听 `*-ws.va.huya.com` Tars 通道，内置 Tars-lite 解码（LE 优先、BE 兜底） |
| 抖音 | DOM **或** 协议 Hook（智能选择） | DOM 模拟（绝无双发） | 被动监听 `webcast*-ws-web-*.douyin.com` im 通道，protobuf-lite 解码，只读不发 |
| B 站 | DOM **或** 协议直连（智能选择） | DOM 模拟 / 原生直发（可选） | wss 直连（WBI 签名），唯一打通「采集 + 直发」的平台 |

### 工程形态

- **分发**：单文件 `dist/latest.user.js`，零依赖、无构建步骤，Tampermonkey 安装即用，
  自动更新指向同一路径；
- **代码组织**：SECTION 模块化 + JSDoc 注释；去重 / 安全阀 / 房间号解析等纯逻辑
  抽成独立核心，可脱离页面环境做单元测试，构建时内联回单文件；
- **行为基线策略**：每次升级都以真实浏览器端到端复现为验收门槛，拒绝「静态分析声称已修复」
  的假阳性；
- **变更记录**：完整历史与 P0 / P1 / P2 分级说明见 [CHANGELOG.md](./CHANGELOG.md)；
  `dist/` 内同时保留各历史发布留档，供回退与对照。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（或同系用户脚本管理器）；
2. 打开 [latest.user.js](./dist/latest.user.js) 的 **Raw 原始文件页**，
   Tampermonkey 会自动弹出安装（也可从 [Releases](./releases/latest) 下载
   `latest.user.js` 安装，自动更新即指向该资产）；
3. 升级前请先删除旧版脚本，防止同一页面双实例并发发送；
4. 打开任意直播间，右下角出现 🤖 悬浮面板即成功——首次使用请在面板点一次红色
   「已知晓并启用」风险确认，然后拨动开关开始运行（旧版设置会自动继承）。

## 使用

- **面板开关** = 启动 / 停止自动复读；面板可折叠、可拖动，位置会记忆；
- **引擎模式**：`自动`（智能选择，协议失败自动回落 DOM）／`协议直连`／`DOM（兼容原行为）`；
  斗鱼可在设置页选「协议路线」：自连优先（Hook 兜底）／仅自连／仅 Hook 页面；
- **发送通道**：默认 DOM 模拟发送；B 站可在设置页开启原生直发；
- **设置页**：候选 / 去重 / 屏蔽词 / 优先词 / 模式阈值 / 主题 / 日志，
  支持配置导入导出与诊断快照；
- **安全阀**：分钟 / 小时 / 日硬上限、最小间隔、同句冷却、平台风控熔断——计数持久化，
  刷新与多标签页合并后依然生效。
