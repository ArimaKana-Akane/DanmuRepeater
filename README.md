# 🤖 烂梗机

> 多平台直播弹幕自动复读助手 · Tampermonkey 用户脚本

[![Tampermonkey](https://img.shields.io/badge/Tampermonkey-✓-green.svg)](https://www.tampermonkey.net/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

监听 **斗鱼 / 虎牙 / Bilibili / 抖音** 直播间的弹幕流，识别高频 / 热门弹幕并自动复读。

> ⚠️ **免责声明**：本项目仅用于学习与个人娱乐。请遵守各平台服务条款与社区规范，
> 合理控制使用频率，勿用于刷屏 / 引流 / 广告。使用者自行承担一切后果。

## 平台支持

| 平台 | 采集 | 发送 |
|---|---|---|
| 斗鱼 | DOM / 协议（自连 + Hook，路线可配） | DOM 模拟 |
| 虎牙 | DOM / 协议 Hook | DOM 模拟 |
| 抖音 | DOM / 协议 Hook | DOM 模拟（绝无双发） |
| B 站 | DOM / 协议直连 | DOM 模拟 / 原生直发（可选） |

任一协议路线认证成功才接管（暂停 DOM），失败自动回落——采集全程不中断。

## 功能特性

- **双引擎互斥**：DOM 兼容保底 + 协议引擎四平台覆盖，自动智能选择、失败回落；
- **智能去重与实时候选**：2 分钟滑动窗口统计，候选随直播话题实时刷新，`66666` 等纯数字可正常复读；
- **证据驱动发送**：按「输入框是否清空」的实测证据决定是否补 Enter——根治各平台「一次发两条」；
- **分层安全阀**：分钟 / 小时 / 日硬上限、最小间隔、同句冷却、风控熔断；计数持久化，刷新与多标签合并后依然生效；
- **多标签协作**：leader 选举，同一弹幕只由一个标签页发送；
- **完整可观测性**：面板、设置页、事件日志、60s 采集摘要、配置导入导出与诊断快照；
- **零依赖单文件**：一个 `.user.js`，安装即用。

## 安全护栏（fail-closed）

- 首次启用需在面板点一次红色「已知晓」风险确认，未确认不运行；
- 安全配置只能合并、只能更严：任何残缺配置都无法绕过硬上限；
- 触发风控熔断 / 随机跳过的发送**不重试**——宁可偶发漏发，绝不重复发送。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（或同系用户脚本管理器）；
2. 打开 [latest.user.js](./dist/latest.user.js) 的 **Raw 原始文件页**，Tampermonkey 会自动弹出安装
   （也可从 [Releases](./releases/latest) 下载 `latest.user.js`）；
3. 打开任意直播间，右下角出现 🤖 悬浮面板即成功——首次使用请在面板点一次红色
   「已知晓并启用」风险确认，然后拨动开关开始运行（旧版设置会自动继承）。

已装旧版的用户无需手动操作：`@updateURL` 指向 Releases 最新资产，Tampermonkey 会自动升级。
（自动更新为原地替换；手动另装新脚本文件前请先删除旧版，防止同页面双实例并发发送。）

## 使用

- **面板开关** = 启动 / 停止自动复读；面板可折叠、可拖动，位置会记忆；
- **引擎模式**：`自动`（智能选择）／`协议直连`／`DOM（兼容原行为）`；
  斗鱼可在设置页选「协议路线」：自连优先（Hook 兜底）／仅自连／仅 Hook 页面；
- **发送通道**：默认 DOM 模拟发送；B 站可在设置页开启原生直发；
- **设置页**：候选 / 去重 / 屏蔽词 / 优先词 / 阈值 / 主题 / 日志，支持配置导入导出与诊断快照。
